# COBOL 账户管理系统测试计划

## 测试目标

验证当前 COBOL 账户管理系统的菜单流程、操作分发、余额读取与写入，以及充值和扣款业务规则。本测试计划也可作为后续 Node.js 重构的行为基准：Node.js 实现应保持已确认的业务行为，或由业务相关方明确批准行为变化。

## 测试范围与约定

- 程序入口：`src/cobol/main.cob`（`MainProgram`）。
- 操作逻辑：`src/cobol/operations.cob`（`Operations`）。
- 余额存储：`src/cobol/data.cob`（`DataProgram`）。
- 初始余额：`1000.00`。
- 余额只保存在内存中，程序重启后恢复为 `1000.00`。
- 金额使用两位小数的 COBOL 数值字段表示。
- 执行测试前，将“实际结果”填写为观察到的输出，并将“状态（Pass/Fail）”填写为 `Pass` 或 `Fail`。

## 业务方确认事项

1. 是否允许 `0.00` 充值和扣款？
2. 是否必须拒绝负数、非数字或超过字段范围的金额？
3. 学生账户是否需要最低余额、每日限额、费用减免或身份验证？当前 COBOL 代码未实现这些规则。
4. Node.js 版本是否需要持久化余额？这会改变当前“重启后恢复 `1000.00`”的行为。
5. 对未知操作类型，Node.js 版本是否应返回明确的错误，而不是静默忽略？
